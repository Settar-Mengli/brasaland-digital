# Menu Allergen Information (Guest)

Brasaland discloses allergens according to the regulations in effect in each country (INVIMA in Colombia, FDA in the United States). Our team can answer allergen questions at any location.

## Main dishes and declared allergens

- **Grilled Sirloin (Lomo a la Brasa):** gluten-free, dairy-free. Marinade contains soy.
- **Brasaland BBQ Ribs:** contains soy (sauce) and may contain trace peanuts on some production lines of the imported sauce.
- **Classic Grilled Chicken:** gluten-free, dairy-free, nut-free.
- **Tropical Salad:** contains nuts (cashew) and dairy (feta cheese).
- **Corn Arepa (side):** contains dairy and egg.
- **House Sauce:** contains soy and sulfites.

## If you report an allergy

1. Tell your server before preparation begins.
2. The kitchen uses clean utensils and a separate prep surface when possible.
3. We never guarantee zero cross-contamination risk — your server will explain this clearly if you have a severe allergy.

There is no certified gluten-free version of the BBQ Ribs due to the imported sauce; we always communicate this when asked.
